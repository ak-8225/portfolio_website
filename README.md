# Akshay Kumar — Portfolio

Modern developer portfolio built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons.
The site opens in dark mode, with a theme switcher and an interactive skills globe.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content edits

Update portfolio content in `src/data/resumeData.ts`.

Assets live in `public/assets/`:
- `profile-speaking.png` — hero portrait
- `cover.png` — subtle hero background photo
- `hidden-gems-project.png`, `breach-ai-project.png` — project previews
- `srm-provisional-degree.png` — linked provisional degree preview in Education
- `barclays-logo.png`, `leap-scholar-logo.png`, `icar-iasri-logo.png`, `abv-iiitm-logo.png`, `srm-logo.png`, `microsoft-logo.png`, `ieee-logo.png` — organization logos
- `cert-azure.png`, `cert-iasri.png`, `cert-leap.png` — certificate previews
- `github.svg`, `linkedin.svg`, `instagram.svg` — social brand icons
- `Akshay_Kumar_Resume.pdf` — resume download

## Deploy (Vercel)

Import [ak-8225/portfolio_website](https://github.com/ak-8225/portfolio_website) into Vercel and deploy.

```bash
npm run build
```
